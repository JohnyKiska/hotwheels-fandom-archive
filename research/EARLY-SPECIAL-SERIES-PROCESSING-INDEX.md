## Processing rules

1. Extract each top-level product table in source order. Preserve source section, table and row positions, source headers, raw row HTML, raw cell HTML, text values, links and image metadata.
2. Keep separate tables and rows separate. Do not merge by Toy #, model name, year, color, or apparent casting identity.
3. Preserve source spelling and anomalies; do not normalize or silently repair values in this extraction layer.
4. Exclude header-only rows. Retain ambiguous/no-header tables with source order and flag them for review.
5. Product tables and gallery images are separate structures. Gallery extraction is not implied by embedded product-table image metadata.
6. Create one CSV and one QA Markdown file per source page; update this index after each batch.
7. CSV schema has 21 columns. Extraction is source-preserving, not canonical database normalization.
